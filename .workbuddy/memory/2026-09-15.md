## 自定义字体 ding 不生效（已修复）
- 原因：`src/assets/css/font.css` 是 0 字节空文件（没有 @font-face），且 `src/main.ts` 从未 import 该 css，导致 `font-family: 'Ding'` 找不到字体、静默回退系统字体。ttf 文件本身正常（2MB，头 00010000）。
- 修复：font.css 写入 @font-face（family 名 'Ding'，src url('../fonts/ding.ttf') format('truetype')，font-display: swap）；main.ts 加 `import './assets/css/font.css'`；App.vue 内联 style 换成 .ding-text class，并带 fallback 字体栈。
- 验证：`npx vite build` 产物含 dist/assets/ding-*.ttf 且 CSS 中 @font-face url 正确；dev server 返回 font.css 内容正常。
- 注意 `npm run build` 会连带跑 type-check 而失败（见上条 TS7/vue-tsc 问题），验证构建请用 `npx vite build`。
